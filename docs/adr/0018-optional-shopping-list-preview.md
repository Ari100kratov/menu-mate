# 0018 Настраиваемый предпросмотр списка покупок

## Статус

Принято.

## Контекст

Предпросмотр списка покупок полезен при первой генерации и когда нужно изменить порции или исключить ингредиенты. При регулярном использовании обязательный промежуточный экран замедляет сценарий, однако скрытая клиентская генерация не должна подменять серверный расчет и отменять предупреждение о замене существующего списка.

## Решение

- В аккаунте хранится настройка показа предпросмотра; для новых и существующих пользователей он включен по умолчанию.
- Настройка меняется на самом экране предпросмотра и в профиле пользователя.
- При отключенном предпросмотре backend сам выбирает все рецепты и ингредиенты диапазона, использует порции позиций меню и выполняет обычный расчет списка.
- Непустой текущий список по-прежнему заменяется только после явного подтверждения.
- Пустая выборка ингредиентов завершается ошибкой и не изменяет текущий список.

## Последствия

Опытный пользователь получает короткий сценарий без потери серверных гарантий. Настройка синхронизируется между устройствами, а предпросмотр остается доступен для точного выбора состава и порций.
