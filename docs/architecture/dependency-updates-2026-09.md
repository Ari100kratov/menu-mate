# Обновление зависимостей: сентябрь 2026

Версии проверены в реестрах npm и NuGet. Обновлены прямые зависимости в пределах текущих основных версий, а также транзитивные зависимости фронтенда в `pnpm-lock.yaml`.

- .NET остается на `net10.0`. Минимальная версия SDK — 10.0.300; `latestFeature` разрешает установленные более новые feature band .NET 10, включая 10.0.400, без перехода на .NET 11.
- Пакеты ASP.NET Core и EF Core: 10.0.11; Extensions Resilience и ServiceDiscovery: 10.9.0.
- Aspire и Aspire.AppHost.Sdk синхронизированы на 13.5.3; OpenTelemetry: 1.18.0; OpenAI SDK: 2.13.0.
- Обновлены Scalar, SonarAnalyzer, Testcontainers и Microsoft.NET.Test.Sdk.
- Обновлены React, Radix, TanStack, Tailwind, Vite, ESLint и остальные пакеты, для которых доступны совместимые обновления. pnpm закреплен на 11.19.0.
- TypeScript остается на 5.9.3, Vitest на 4.1.11, xunit.runner.visualstudio на 3.1.5. Новые основные версии (TypeScript 7, Vitest 5, runner 4) не входят в это совместимое обновление. Пакеты без новых совместимых версий оставлены без изменения.

Публичные HTTP-контракты, целевая платформа и схема базы данных сохранены. Новое правило анализатора учтено передачей `RequestAborted` при записи ответа авторизации.

Проверки выполняются без запуска приложения. Тесты генерации обложек используют подмененный HTTP-транспорт и не обращаются к OpenAI. Интеграционные тесты API требуют Docker/PostgreSQL и отдельной проверки окружения.

Для транзитивных `glob@11`, `fast-uri@3` и `browserslist@4` в `pnpm-workspace.yaml` заданы совместимые исправленные версии: 11.1.0, 3.1.6 и 4.28.9 соответственно. Обычное рекурсивное обновление оставляло уязвимые версии в цепочке Workbox/Babel/Ajv. Переопределения следует пересматривать вместе с обновлениями PWA-инструментов.
