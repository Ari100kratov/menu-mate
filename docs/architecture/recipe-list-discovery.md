# Поиск, фильтры и сортировка рецептов

Список рецептов использует серверную сортировку и пагинацию: порядок определяется до `Skip/Take`, поэтому страницы не перемешиваются при сортировке по дате создания или популярности. Доступные порядки: по алфавиту, сначала новые рецепты и по популярности. При равных значениях сервер использует детерминированные дополнительные поля сортировки.

Сердце остается единственным действием избранного и управляет записью библиотеки. Количество лайков рецепта равно количеству записей `recipes.recipe_library_entries` с его `RecipeId`; оно не относится к конкретной ревизии и не сбрасывается при обновлении рецепта. Нулевое значение возле сердца не показывается. При переключении избранного на карточке обновляется локальный кеш: счетчик и состояние сердца меняются сразу, без повторного запроса и без смены позиции рецепта до следующего обновления списка.

Панель списка состоит из быстрого поиска, кнопки расширенных фильтров и текстового меню сортировки рядом со счетчиком результатов. Меню всегда показывает текущий порядок: по алфавиту, сначала новые или по популярности. В расширенных фильтрах находятся избранное, принадлежность рецепта и теги. Изменения в диалоге применяются только после явного нажатия «Применить»; закрытие диалога отменяет черновик. Кнопка «Сбросить фильтры» сразу применяет значения по умолчанию и закрывает диалог. Категории остаются быстрыми фильтрами под строкой поиска.

Список возвращает не только текущую страницу, но и `totalCount` для тех же фильтров до пагинации. Пока загружены не все страницы, интерфейс показывает «Показано: N из M»; после загрузки всех — «Найдено: M». На мобильном счетчик и текстовая сортировка находятся в одной строке, а длинное название порядка при необходимости сокращается без переноса.

Поле тегов можно закрепить на основной панели. Эта настройка сохраняется локально, как и примененные фильтры и сортировка; настройки библиотеки рецептов и выбора блюда для меню независимы. Красная точка на кнопке расширенных фильтров показывает только активные скрытые условия: избранное, принадлежность или теги, когда поле тегов не закреплено на основной панели.

Администратор видит у каждого пользователя число рецептов, которые тот добавил в избранное. Это число считается по тем же библиотечным записям и не является количеством лайков, полученных его рецептами.

## Просмотр рецепта

Предложение обновить сохраненную ревизию показывается только для чужого рецепта из избранного: у владельца рецепта актуальная ревизия доступна напрямую, поэтому такое действие для него не имеет смысла. Действия рецепта располагаются под его названием, чтобы длинный заголовок не сжимался и не пересекался с кнопками. Основные действия выровнены слева, а кнопка избранного — отдельно у правого края панели. Она имеет ту же высоту, что и остальные действия; счетчик, если он есть, расширяет кнопку влево от сердечка.

Поле выбора тегов использует поверхность карточки, как и остальные поля фильтра, поэтому в светлой теме не выглядит серым отдельным блоком.
